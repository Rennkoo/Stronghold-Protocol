# 个人维护版问题修复记录

## 2026-10-10：Unity 伤害数字字形预编码

- 每次 damage/heal 原来调用整数 ToString 创建临时字符串；现在事件产生时计算绝对值、位数，将最多十个数字编码到 ulong 中，每帧用移位读取字形。保留数字位置、间距、颜色和几何，不建立无界数字字符串缓存。
- 初版每帧整数除法拆位，Editor CPU 对照旧版约 0.1817 ms、新版约 0.1897 ms，没有收益；未将该实现作为最终版本。改为事件时编码，逐帧读取无需除法。初版数据保留在 unity-digits-cpu-20261010.json。
- 最终隔离特效测试旧/新/新/旧分别为 0.2325 / 0.2000 / 0.1646 / 0.1737 ms，平均约 0.2031 / 0.1823 ms，改善约 10%。样本波动明显，此 Editor CPU 数据不代表整体 FPS 收益。末帧顶点、UV、颜色和索引逐项相同，见 unity-packed-digits-cpu-20261010.json。
- 验证零值、十进制位数边界和 int 极值的编码，数字以非负幅值显示；Windows 验证构建成功。对照工具兼容已经提供 AdvanceAndRender 的旧实现，避免重复生成方法。
- 最终 120 单位/59 模型、1920×1080、30 秒预热 + 600 帧压力测试平均 79.56 FPS，p95 18.34 ms，特效峰值 330、丢弃 0；记录 unity-packed-digits-stress-20261010.json。整场原生录像 550 快照/536 事件及最终状态核对再次通过。短测仍不能证明整体提升或稳定 60 FPS；ECS 未变更。
